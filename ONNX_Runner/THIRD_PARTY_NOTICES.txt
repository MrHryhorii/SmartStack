Binary release verification
---------------------------
This source archive is not an inventory of every published build. Before
publishing each Windows, Linux, or container artifact, compare its actual
contents against the notices above and the licenses inside its restored NuGet
packages, including transitive and native dependencies. Preserve required
copyright and license texts in the published artifact.
The publishing helper prepares corresponding source once when needed, checks
the staged hashes, and packages it as a separate release download. The binary
outputs contain SOURCE_ACCESS.txt and SOURCE_MANIFEST.json rather than large
copies of the source package. Offer the matching source package with equivalent
access wherever the binaries are distributed.
Linux builds omit the bundled
Windows DLLs but retain eSpeak data; the Linux system eSpeak and container
packages must be reviewed against the exact image. The default `All` publish
includes Windows DirectML and copies its package terms without blocking build.
NUGET_RESTORE_INVENTORY.txt records all six RID-specific restore graphs from
the 20260924-235314 publish run. The script captures each exact restore graph
and copies available package license and notice files from the NuGet cache.
Inspect its reports and the actual native binaries. The Microsoft.AI.DirectML
license issue above remains unresolved for the DirectML binary variant.

When conveying the bundled Piper eSpeak DLL, make its corresponding fork
source and build scripts available with equivalent access alongside the
binary. Do the same for source and other required materials for the two
prebuilt browser decoder bundles and their LGPL components. A repository
home-page link alone is not a substitute for these distribution steps.
Linux/container publishes should also be checked for Windows-native files
copied from PiperNative/ even when Linux uses a separately installed eSpeak.

Check the Piper model card and license against the exact weights bundled in
each published build. If a build also contains OpenVoice model weights, check
its model card and notices against those files as well.
