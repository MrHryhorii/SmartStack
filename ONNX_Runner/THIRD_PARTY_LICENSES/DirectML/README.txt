Microsoft.AI.DirectML 1.15.4: which license applies?
===================================================

This directory contains unmodified files from the Microsoft.AI.DirectML
1.15.4 NuGet package, as supplied by the project author:

* LICENSE.txt: Microsoft Software License Terms for the DirectML
  redistributable software, including the native DLL.
* LICENSE-CODE.txt: MIT license for code material covered by that file.
* ThirdPartyNotices.txt: notices for included third-party components.

Microsoft's DirectML GitHub source repository is also published under MIT:
https://github.com/microsoft/DirectML/blob/master/LICENSE

These texts address different materials. The MIT text does not replace
LICENSE.txt for a prebuilt DLL taken from the redistributable package.
Section 1(a) of LICENSE.txt expressly permits distribution of DirectML
in Windows or Xbox applications and services developed with machine-learning
tools and frameworks, subject to its terms. This project distributes the
Windows DirectML build under that permission and includes the applicable
package license and third-party notices. The project's own code remains
GPL-3.0-or-later; the DirectML DLL retains its separate package terms.
